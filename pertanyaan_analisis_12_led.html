B. Pertanyaan Analisis

Pengendalian 12 Lampu LED pada Pin Digital 2 sampai 13

Bagian ini berisi jawaban analisis mengenai fungsi perintah Arduino, cara kerja pola Flip-Flop, pengaruh nilai delay, dan pembuatan pola Running LED.

1. Jelaskan fungsi dari perintah pinMode(ledPins[i], OUTPUT); dalam sketch di atas!

Jawaban

Perintah pinMode(ledPins[i], OUTPUT); berfungsi untuk mengatur seluruh pin Arduino yang terhubung dengan 12 LED (Pin 2 sampai Pin 13) sebagai pin keluaran (output), sehingga Arduino dapat mengendalikan setiap LED untuk menyala dan mati.

2. Bagaimana cara kerja fungsi digitalWrite() dalam menghasilkan efek Flip-Flop?

Jawaban

Fungsi digitalWrite() bekerja dengan memberikan logika HIGH untuk menyalakan LED dan LOW untuk mematikan LED. Pada 12 LED, perintah ini mengatur kelompok LED ganjil dan genap agar menyala secara bergantian dengan bantuan delay(), sehingga menghasilkan efek Flip-Flop.

3. Apa yang terjadi pada rangkaian jika nilai delay() diubah dari 1000 menjadi 200? Jelaskan alasannya!

Jawaban

Jika nilai delay() diubah dari 1000 menjadi 200, pergantian nyala 12 LED menjadi lebih cepat. Hal ini karena waktu jeda berkurang dari 1 detik menjadi 0,2 detik, sehingga LED menyala dan mati dengan interval yang lebih singkat.

4. Jika Anda ingin membuat 12 LED menyala berurutan (Running LED) dari LED 1 sampai LED 12, kemudian kembali ke LED 1, bagaimana Anda akan memodifikasi sketch di bagian void loop()?

Jawaban

Saya akan menggunakan perulangan for untuk menyalakan 12 LED secara bergantian dari Pin 2 sampai Pin 13, kemudian mematikannya satu per satu dengan bantuan digitalWrite() dan delay().

Contoh program pada bagian void loop():

void loop() {
  // Running LED maju
  for (int i = 0; i < 12; i++) {
    digitalWrite(ledPins[i], HIGH);
    delay(500);
    digitalWrite(ledPins[i], LOW);
  }

  // Running LED mundur
  for (int i = 10; i > 0; i--) {
    digitalWrite(ledPins[i], HIGH);
    delay(500);
    digitalWrite(ledPins[i], LOW);
  }
}

Catatan: Program tersebut menggunakan 12 LED pada Pin 2–13. Pola bergerak dari LED pertama ke LED kedua belas, kemudian kembali ke arah LED pertama secara berulang.
